- # Heretical Campaign (D&D 5e Compatible)

- This directory contains all Heretical campaign setting content in a format compatible with D&D 5e registries and tools.

- ## Structure

- **setting.md:** Core lore (locations, history, timeline)
- **npcs/**: Put Markdown files here for each campaign notable, using one file per NPC. Use `../dnd-lantae/lore/campaigns/lantae/npcs/` as a template (e.g. see `elara-moonwhisper.md`).

- ## House Rules or Additions (optional)

- If your campaign requires homebrew mechanics, create `house-rules.md` here (optional). When possible, cite specific D&D 5e rules as a baseline and describe any changes/extensions clearly for player transparency.

- ## D&D 5e Compatibility Checklist

- All factions, spells, and classes referenced in this campaign are assumed to be standard D&D 5e unless otherwise noted.
- Cross-reference any custom mechanics with the official D&D SRD.

- ## Extending This Campaign

- To add NPCs: Place a file in `npcs/` with frontmatter (name, race, class, role, stat block if needed) and narrative description.

- To add maps/locations: Either add Markdown lore here or create new subfolders if adding extensive custom content.

- To connect new narrative elements to the registry,
- link to mechanics (classes/races) using the same names/keys found in core D&D (`../dnd-lantae/mechanics/core`).
