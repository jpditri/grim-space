# Grim-Space: Shared Campaign Repository

This repository contains lore and campaigns for collaborative D&D gaming, organized for integration with campaign management systems.

## Campaigns

### Dresden Lite - Urban Fantasy (Boston)
**Setting**: Modern Boston-North Shore Massachusetts  
**Theme**: Hidden supernatural world where magic must stay secret  
**Key Features**:
- Real Boston locations with supernatural elements
- Modern firearms mechanics with D4 hit system
- Magic concealment rules and masquerade elements
- Human-only character restriction

### Kepharion - Bio-Crystalline Sci-Fi
**Setting**: Planet Kepharion with dual cognition lifeforms  
**Theme**: Hard sci-fi exploring consciousness and memory  
**Key Features**:
- Xenocortex dual-brain system (biological + crystalline)
- Pattern-locking memory mechanics
- Energy credit economy and multiverse travel
- Sanity system based on ability score modifiers

```
│   ├── mechanics/         # Modern combat and magic rules

│   ├── lore/              # Xenocortex system and consciousness
│   ├── locations/         # Crystalline cities and space stations
│   ├── npcs/              # Xenocortex species and space travelers

```

## Cross-Campaign Elements

### The Penance Sandwich
A supernatural food item featured in the Dresden Files campaign, served in certain supernatural establishments around Boston.

### Symbolic Systems
Kepharion features crystalline patterns that store knowledge and power within the xenocortex consciousness system.

### Hidden Knowledge
Both campaigns feature secret organizations, hidden lore, and the tension between public facade and hidden truth.

## Integration Notes

This repository is designed to work with D&D campaign management systems that support:
- Campaign switching and configuration
- AI-powered content generation optimized per campaign
- Cross-campaign lore tracking and references
- Collaborative content development

## Contributing

When adding content:
1. Follow the established directory structure
2. Include proper frontmatter with campaign tags
3. Cross-reference related content between campaigns
4. Maintain setting consistency within each campaign world
